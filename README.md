# MEDORA — тренажёр будущего стоматолога

Учебная веб-платформа для студентов-стоматологов. Работает в браузере и на телефоне, без регистрации.

## Модули (MVP)

- **Интерактивная одонтограмма** — постоянный и временный прикус, отметки по поверхностям (С, Р, Pt, R, П, К, Г, О, И), автоматический подсчёт КПУз/КПУп (кп для временных зубов) с оценкой по ВОЗ, копирование и печать формулы.
- **Калькуляторы индексов** — OHI-S, Фёдорова–Володкиной, PHP, API, PMA, CPITN, КПУ с интерпретацией и критериями оценки.
- **Атлас зубов** — номер в системах FDI / Universal / Palmer, латинское название, корни, каналы, сроки прорезывания, клинические особенности.
- **Тренажёр нумерации** — «найди зуб», «назови номер», латынь, перевод FDI → Universal.

## Дальше

Рентген-тренажёр, клинические кейсы, кабинет преподавателя для группы, проверка материалов кафедрой.

## Запуск локально

Статический сайт без сборки:

```
python -m http.server 8000
```
